**For Dispatcharr 0.33.0**, like v276. What is new is how it is installed and kept up to date:

- **Dispatcharr and Dispatch More updated in one command** (Linux / LXC):

  ```
  curl -fsSL https://github.com/ckegels/dispatch-more/releases/latest/download/quick-install.sh | sudo bash -s -- --upgrade
  ```

  Dispatcharr is updated to the version the newest Dispatch More is made for, never past it, the
  way it was installed (`debian_install.sh`, or the Proxmox community script's own update steps
  with its backup), with Dispatch More taken off first and put back after. Dispatcharr's own
  updaters always take the newest Dispatcharr, which may have no Dispatch More release yet.
- **Docker:** with Dispatch More's start script in the compose file, pulling a newer Dispatcharr
  image now gets the release made for it by itself at the next start (`DISPATCH_MORE_AUTO_UPDATE=0`
  keeps the release as it is). This takes effect from this release on: the start script lives in
  `/data` and comes with the release.
- **The recordings worker on the Proxmox community script's install:** it was never added there
  (its Celery service runs a start script), so every recording took one of the normal worker's
  four slots for the whole programme. It now runs there too, with the community script's own
  files left untouched.
- **Close channels nobody watches** (Jellyfin, Settings → Media Servers, open the server; off
  until you switch it on): Jellyfin sometimes keeps reading a channel after its viewer left, and
  Dispatcharr then keeps the channel and a provider connection open for nobody. With the switch
  on, Jellyfin's connection to a channel it has not played to anybody or recorded for 3 minutes
  is closed. Anybody else on the channel keeps watching; when Jellyfin cannot be asked, or names
  something that cannot be placed, nothing is closed. Not offered for Plex, which cannot say what
  it records.
- **Jellyfin recordings are seen again:** what Jellyfin is recording was read wrongly, so the
  channel overlap could take a Jellyfin recording for a channel somebody had left.
- Uninstalling leaves no empty Dispatch More folders behind (Python's compiled copies kept them).
