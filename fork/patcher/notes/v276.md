**This release is for Dispatcharr 0.33.0.** v275 stays the release for Dispatcharr 0.31.0; the
install command picks the one that fits the Dispatcharr you have.

Coming from v275 or older on Linux: update Dispatcharr to 0.33.0 as you always do, then run the
install command again. It takes the old release off without putting 0.31.0's files over 0.33.0's.
Or take Dispatch More off first with the newest uninstaller, which is safe whatever happened
since:

```
curl -fsSL https://github.com/ckegels/dispatch-more/releases/latest/download/quick-install.sh | sudo bash -s -- --uninstall
```

After Dispatcharr was updated, do not use the uninstaller a release before v276 left in
`/var/lib/dispatch-more/` (`uninstall.sh`): it puts the old version's files back.

Changed with Dispatcharr 0.33.0:
- "Keep the guide's past" is gone: Dispatcharr keeps guide history itself now (Settings → EPG,
  minimum days). Set it to what you had.
- Faster failover now shortens Dispatcharr's new Stream Startup Timeout (Settings → Proxy) for
  arrTV, instead of a check of its own.
