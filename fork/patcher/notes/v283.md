**For Dispatcharr 0.34.1.** The same as v282, with one fix to the install command:

- **`--upgrade` works when run from the Proxmox host** (`pct exec <id> -- bash -c '... | bash -s -- --upgrade'`).
  `pct exec` runs commands without `/usr/local/bin` in the path, where the Proxmox community
  script installs `uv`, so the upgrade took a community-script install for an unknown one and
  stopped with "Nothing was changed". It now looks in the usual places itself.

To go from Dispatcharr 0.33.0 (v281) to 0.34.1 and this release in one go:

```
curl -fsSL https://github.com/ckegels/dispatch-more/releases/latest/download/quick-install.sh | sudo bash -s -- --upgrade
```

What 0.34.1 brings with Dispatch More is in the v282 notes.
