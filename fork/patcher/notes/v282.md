**This release is for Dispatcharr 0.34.1.** v281 stays the release for Dispatcharr 0.33.0; the
install command picks the one that fits the Dispatcharr you have.

To go to Dispatcharr 0.34.1 and this release in one go (Linux/LXC, Dispatcharr's own installer or
the Proxmox community script):

```
curl -fsSL https://github.com/ckegels/dispatch-more/releases/latest/download/quick-install.sh | sudo bash -s -- --upgrade
```

On Docker, update the image to 0.34.1: the start script fetches this release by itself.

With Dispatcharr 0.34.1:
- **Plugin actions run on Linux/LXC.** Dispatcharr 0.34 runs them on a queue of their own, which
  the Linux install and the Proxmox community script's worker did not listen to: every action
  waited 55 seconds and failed. Dispatch More's worker setup now includes it.
- **Stream Check keeps every audio track**, with its language, in the shape Dispatcharr 0.34's
  audio badge shows, and now sees films and episodes being watched, so it no longer takes the
  connection of a provider someone is watching a film on.
- **The Logs page hides provider logins** (Diagnostics → Logs and its download), as Dispatcharr
  0.34 does for Docker's logs, unless "Redact Credentials in Logs" is switched off.
- **A recording whose sound Dispatcharr had to rebuild** is no longer called "ok" by the health
  check: it says so.
- The guide window matches programmes whose channel id has spaces around it, as Dispatcharr 0.34
  now does.

Also fixed:
- **arrTV reports no longer keep provider logins.** Some kinds of links (a login before the host,
  Xtream links without `/live/`, the username in a playlist link, cookies, links quoted in the
  server's part of a report) were stored as they came. Reports kept before are cleaned once.
- **On a Linux install, a recordings worker that does not start** no longer leaves recordings with
  nobody to run them: the normal worker takes them over again.
- Dates and times on Dispatch More's pages follow Settings → UI (time zone, date format including
  0.34's ISO 8601, 12/24-hour clock).
- Channels with an override are shown by that name on Diagnostics, Stream Check and in arrTV's
  watch together.
- Logo collections added on the Logos page are fetched the safe way Dispatcharr 0.34 fetches
  images (never from the server itself).
