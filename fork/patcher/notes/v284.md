**For Dispatcharr 0.34.1.** The same as v283, with one fix to the one-command upgrade:

- **`--upgrade` keeps the caption worker.** The upgrade takes Dispatch More off while it updates
  Dispatcharr, and that removed the optional caption worker with its models, to be installed
  again from the Subtitles tab. Now the worker is stopped meanwhile and comes back with the models
  it had. The uninstall command and the page's Uninstall button still remove all of it.

If an earlier `--upgrade` removed your caption worker, install it once more from Channel Manager →
Subtitles; later upgrades keep it.

```
curl -fsSL https://github.com/ckegels/dispatch-more/releases/latest/download/quick-install.sh | sudo bash -s -- --upgrade
```
